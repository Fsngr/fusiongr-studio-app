# FusionGr Studio — publicación (GitHub Pages)

Este repositorio solo contiene el **build compilado** de FusionGr Studio
(`index.html`, un único archivo autocontenido) para servirlo gratis con
**GitHub Pages**. No hay código fuente aquí.

- **App en vivo:** https://fsngr.github.io/fusiongr-studio-app/
- **Código fuente:** https://github.com/Fsngr/fusiongr-studio (privado)
- **Se actualiza solo** en cada push a `master` del repo de código, vía
  `.github/workflows/deploy-pages-mirror.yml` (ver ese repo).
- También publicado en Netlify: https://papaya-druid-6fba0c.netlify.app

`index.html` es exactamente lo que corre en el navegador de cada visitante — no
contiene nada que no estuviera ya visible con "Ver código fuente" en cualquiera
de las dos URLs de arriba.
